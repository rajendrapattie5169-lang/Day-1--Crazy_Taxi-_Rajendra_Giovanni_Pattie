## 1. Rangkuman Materi Workshop

Pada hari pertama Proyek Workshop, peserta mendapatkan beberapa materi yang berkaitan dengan pengembangan proyek, pemanfaatan AI, pengelolaan perubahan, serta pengenalan lingkungan akademik di JTIK.

### A. Building with AI dan Prompt Engineering

Materi pertama membahas pemanfaatan AI dalam membantu proses pembuatan dan pengembangan aplikasi. Salah satu hal penting yang dipelajari adalah *prompt engineering*, yaitu cara menyusun instruksi atau masukan agar AI dapat memberikan hasil yang tepat, relevan, dan sesuai kebutuhan.

Prompt yang baik perlu memiliki beberapa unsur, yaitu:

- **Role:** peran yang perlu dijalankan oleh AI.
- **Task:** tugas yang harus dikerjakan.
- **Context:** latar belakang atau konteks tugas.
- **Format:** bentuk hasil yang diharapkan.

Pemberian konteks dan instruksi yang spesifik dapat membantu AI menghasilkan jawaban yang lebih sesuai. Materi juga menekankan pentingnya memeriksa hasil AI dan tidak langsung menganggap aplikasi atau kode sudah berjalan sebelum diuji.

### B. Pengenalan Git dan GitHub

Materi berikutnya membahas Git dan GitHub serta perbedaan keduanya.

- **Git** adalah sistem version control yang digunakan untuk melacak perubahan pada file atau proyek, termasuk perubahan yang dilakukan dan riwayatnya.
- **GitHub** adalah platform berbasis web untuk menyimpan repository Git secara online dan mendukung kolaborasi.

Dengan version control, perubahan dalam proyek dapat dikelola dan ditelusuri sehingga proses pengembangan menjadi lebih teratur.

### C. Git Workflow

Dalam Git terdapat beberapa bagian penting pada alur kerja:

1. **Working directory:** tempat file proyek dikerjakan dan diubah.
2. **Staging area:** tempat menyiapkan perubahan yang akan dimasukkan ke commit berikutnya.
3. **Git directory/repository:** tempat Git menyimpan informasi dan riwayat perubahan proyek.

Alur ini membantu pengguna memahami bagaimana perubahan file dipilih, disiapkan, lalu disimpan dalam riwayat proyek.

### D. Perintah Dasar Git

Beberapa perintah Git yang diperkenalkan dalam workshop antara lain:

| Perintah | Fungsi |
|---|---|
| `git init` | Membuat repository Git baru di folder proyek. |
| `git add .` | Menambahkan perubahan file ke staging area. |
| `git commit -m "pesan"` | Menyimpan perubahan ke riwayat repository dengan pesan commit. |
| `git remote add <name> <url>` | Menghubungkan repository lokal dengan repository remote. |
| `git push origin main` | Mengirim commit dari branch main ke repository remote. |
| `git pull origin main` | Mengambil dan menggabungkan perubahan dari repository remote ke branch lokal. |
| `git clone <url>` | Menyalin repository remote ke komputer lokal. |

### E. Persiapan Git, VS Code, dan SSH

Workshop juga membahas persiapan perangkat untuk pengembangan proyek, meliputi instalasi Git, pemeriksaan versi Git, pengaturan identitas pengguna melalui `git config`, serta persiapan Visual Studio Code.

Selain itu, diperkenalkan penggunaan SSH key untuk autentikasi dan menghubungkan komputer dengan GitHub. Materi mencakup pembuatan SSH key, penambahan key ke SSH agent dan GitHub, serta pemeriksaan koneksi.

### F. Latihan Proyek Student Task Planner

Sebagai gambaran praktik, peserta diperkenalkan pada proyek sederhana bernama **Student Task Planner**. Panduan kegiatan mencakup penggunaan platform berbantuan AI, penulisan prompt untuk membuat aplikasi, inisialisasi Git, commit dan push ke GitHub, kemudian melakukan perubahan dan mengunggah pembaruan kembali.

## 3. Poin Penting dan Pengetahuan Baru

Beberapa hal penting yang saya pelajari dari kegiatan Day 1 adalah:

1. Menyusun prompt AI dengan role, task, context, dan format agar hasilnya lebih terarah.
2. Memahami perbedaan Git sebagai sistem version control dan GitHub sebagai platform penyimpanan serta kolaborasi repository.
3. Memahami alur kerja Git, mulai dari working directory, staging area, hingga repository.
4. Mengenal perintah dasar Git untuk mengelola perubahan dan mengunggah proyek.
5. Mengetahui bahwa Git dan VS Code perlu dikonfigurasi sebelum digunakan dalam alur kerja pengembangan.
6. Mengenal SSH key sebagai salah satu cara autentikasi ke GitHub.
7. Memahami gambaran alur pembuatan aplikasi berbantuan AI, kemudian mengelola perubahannya menggunakan Git dan GitHub.
8. Mendapatkan pengenalan mengenai kurikulum Merdeka di perguruan tinggi, MBKM, MSIB, serta visi dan misi JTIK.
